# ADR-0005: 会话 O(1) 增量追加持久化方案

每个会话存储为两个文件：`{id}.jsonl`（纯轮次追加）和 `{id}.meta.json`（轻量元数据）。轮次记录使用 `JSON.stringify` + 换行符追加到 JSONL 文件（O(1) 文件追加），避免反序列化-追加-全量重写。替代方案是单个 JSON 文件（`{id}.json`）记录所有轮次，但每次追加需要读-改-写整个文件（O(n)）。元数据独立存储为小型 JSON 文件（~150 字节），每次追加轮次时同步更新。考虑到每条轮次记录的 Token 预估（几千 token），未来单个 JSONL 文件过大时可引入文件切割或轮次合并策略。
